1. Quick Start (5-Minute Guide)

When you open the portal, you'll land on the Students page. This is your starting point for everything.

The Students page — your starting point. Search by name or email, then click a student to open their workspace.
Getting Started in 5 Steps

1. Click + New Applicant (top right)
2. Fill in student details + first university application
3. Complete the intake (required sections only)
4. Click + Add Document → choose type → enter prompt
5. Click Generate Document → wait → edit → approve → download

1

Create an Applicant

Click + New Applicant on the Students page. You'll see a form with two sections:

New Applicant page — fill in student details and their first university application in one go.

Section 1: Student Details

  • First Name and Last Name — required
  • Email — required, used to identify the student
  • Phone and Country — optional but recommended

Section 2: First Application

  • University — type to search (required)
  • Program — e.g. "MS Machine Learning" (required)
  • Degree — MS, MEng, MA, MBA, PhD, Bachelor, or Other (required)
  • Department, Country, Intake, Intake Year — optional
What happens next

Click Create Applicant & Application →. You'll be automatically redirected to the Application Workspace where you complete the intake, create documents, and generate.

Tip

You can add more applications for the same student later from their student workspace page.

Student Workspace — after creating an applicant, you'll see their profile card and all their applications.
2

Complete the Application Intake

After creating an applicant, you land on the Application Workspace. The status box shows what information is missing:

Application Workspace — the central hub. The status box shows missing required answers with a direct link to complete them. When ready, it shows "✓ Applicant information ready".

The Intake Wizard

Click Complete N Missing Answers → to start the wizard. It shows you one section at a time, only the required ones:

Intake — Student Details section. Fill in personal info and education history. The CV upload option is also available here.
Intake — Master's Motivation. Why the student wants to pursue this master's degree.
Intake — Work Experience. Jobs, internships, and research roles.
Intake — Academics & Projects. Projects, subjects, and skills.
Intake — Country Questions. The questionnaire adapts to the selected destination country.
Intake — Career Goals. Short-term and long-term career objectives.
Intake — Program / University Info. Now only collects the official source URL. Document-specific requirements have moved to document creation.
How the wizard works

Fill in each section and click Save & Next Missing Answer →. The wizard automatically takes you to the next missing section. When all required sections are done, you'll see "✓ All required information complete".

Upload a CV (Optional Shortcut)

Instead of filling in each section manually, you can upload the student's CV to auto-fill education, experience, projects, and skills:

The "Upload CV to pre-fill instead" link on the Application Workspace. Click it to open the upload area.
How it works

1. Click "Upload CV to pre-fill instead" on the application workspace
2. Choose a PDF, DOCX, or TXT file
3. The system extracts education, experience, projects, and skills
4. Review the extracted data before applying
5. Click "Apply" to fill the intake automatically

Important

CV upload is a shortcut — you should still review the extracted data for accuracy. The AI uses this information to write documents, so incorrect data leads to incorrect documents.

3a

Generate a Document with AI

After creating a document, you'll see the Document Workspace. Click Generate Document to start the AI pipeline:

Document Workspace — the generation hub. Click "Generate Document" to start the 6-stage AI pipeline.

The 6 AI Stages

The AI pipeline runs 6 stages automatically. You'll see live progress:

#StageWhat it does
1Prepare (Planner)Plans the document structure and selects relevant evidence from the student's approved facts
2Write (Writer)Writes the first draft using only approved student evidence — never invents facts
3Review (Quality Reviewer)Checks the draft for coverage, accuracy, and requirement compliance
4Polish (Language Calibrator)Refines language, tone, and readability
5Finalize (Bounded Finalizer)Combines all stages into the final document, filtering to only relevant evidence
6Verify (Fact Reviewer)Fact-checks every claim against the student's approved evidence ledger
What to expect

The pipeline typically takes 1-3 minutes. You'll see a progress bar with the current stage. You can cancel at any time. When complete, you'll see the word count, fact-check results, model used, and cost.

Important

The AI only uses approved student facts from the intake. It will NOT invent information. If facts are missing, it will leave gaps or use safe fallbacks — never fabricate.

3b

Edit, Save Versions, and Approve

After generation, the document opens in a rich text editor:

Document Workspace — rich text editor with word count, prompt info panel, and export options on the right.

Editing

  • Click in the editor and make changes — it's a full rich text editor
  • The word count updates live at the bottom
  • Click Save Changes to update the current version, or Save as New Version to create a new one

Version History

All versions are listed at the bottom. Each version shows who created it, the model used, cost, and word count:

Version History — all versions are preserved. View, edit from any version, or approve any version.

Approving a Version

  1. Select the version you want to approve in Version History
  2. Click Approve
  3. A confirmation dialog appears — click Approve Document
Tip

You can approve even if word count warnings appear. The consultant is the final authority. You can also approve a different version later.

Deleting Documents and Applications

Delete a Single Document

On each document card, click Delete (small red text, bottom right). A confirmation panel appears:

Delete confirmation

"Delete 'Visa SOP'? This will permanently delete this document, its generated versions, and its generation history. Other documents and the application will not be affected."

  • Only the selected document is deleted — by document ID, never by type
  • Other documents are untouched
  • The application and student remain
  • You cannot delete a document while generation is in progress

Delete an Application

On the application workspace, click Delete application. This deletes the application and ALL its documents, versions, and generation history. The student profile remains.

Delete a Student

On the Students list, click Delete on a student row. This deletes the student, their profile, and ALL applications with their documents and generation history. This cannot be undone.

Warning

Deletions are permanent. There is no undo for any delete operation. Always confirm the confirmation dialog before proceeding.

15. Troubleshooting

"I can't generate a document"

Cause: The intake is not complete.

Fix: Go back to the application workspace and click Complete N Missing Answers →. Fill in all required sections (Student Details, Academics & Projects, Work Experience, Master's Motivation, Country Questions, Career Goals).

"The generation is stuck"

Cause: The AI pipeline may have timed out or the server is processing.

Fix: Wait 2-3 minutes. If the progress card shows "Generation appears interrupted", click Check Again. If it's still stuck, click Cancel Generation and try again.

"The generated document has gaps or says information is missing"

Cause: The AI only uses approved student facts. If the intake is incomplete, it won't invent information.

Fix: Go back to the intake and complete the missing sections. Then regenerate.

"I see 'DOCUMENT_GENERATION_IN_PROGRESS' when trying to delete"

Cause: You can't delete a document while the AI is generating it.

Fix: Wait for generation to complete or cancel it first, then delete.

"The word count warning appears"

Cause: The document is outside the word limit range.

Fix: This is an advisory warning only. You can still approve and export. Edit the document to adjust the word count if needed.

"I want to create another document of the same type (e.g., a second Essay)"

Yes, this is supported. Click + Add Document, select the same type, and give it a different title. Each document is independent with its own prompt and requirements.
